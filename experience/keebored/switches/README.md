# Switches
Because I am using just 4 keys, I can easily use an analog for my keys. This provides a few benefits, mainly the fact that input is not a binary 1 or 0, instead a range from 1 to 0. With this, I can make the firmware do pretty much anything in terms of actuation, like send input at 1% actuation if for some reason I wanted to do that.

## Owlab Ti HE
These switches (according to a few subreddits and product reviews) are well regarded for their sound, which is not as important to me as just having HE switches.
